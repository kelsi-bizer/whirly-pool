# Whirly Pool

A one-screen iPhone game. A beach ball drops into a light blue pool; tilt your phone to steer it into the whirlpool drain in the middle.

**Play:** https://kelsi-bizer.github.io/whirly-pool/ (open in Safari on iPhone, tap "Drop the ball", allow motion access, then tilt).

On a computer, drag with the mouse or use the arrow keys.
